# P1 · Simulation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (chosen: inline, one fresh reviewer at
> the end). Steps use `- [ ]`. Commands run from the repo root.

**Goal:** the C++ simulation (`src/core`, commit e25ed5f4) as a pure C# library, proven equal to the C++ frame by frame.
**Architecture:** one C# file per C++ file, translated line by line (spec: code map, translation rules). The C++
`sim_test` gets a `trace` mode that prints scenario traces and data dumps; the C# tests replay the same scenarios and
compare numbers. The game's C++ code is not changed.
**Tech stack:** C# 9 (Unity 6000.6.9f1, Mono), NUnit (Test Framework 1.8), C++17 (trace mode), Python 3 (hitfit).
**Spec:** `docs/unity/PORT_PLAN.md`, sections "Translation rules" and "P1". The C++ wins over this list.

## Global constraints
- Code in `unity/Assets/Scripts/Core/`, namespace `ClashHorizon.Core`; tests in `unity/Assets/Tests/EditMode/`,
  namespace `ClashHorizon.Tests`.
- Names: types and methods PascalCase; fields, locals and enum members keep the C++ names. A file's free functions
  are static methods of one static class (`math.hpp` -> `MathUtil`), used with `using static`. `enum MoveId` becomes
  `static class MoveId` with `const int` members (array indices).
- Floats: `float` and `MathF` only. `std::min/max` on floats -> `Minf(a,b) => b < a ? b : a`, `Maxf(a,b) => a < b ?
  b : a`. `std::round` -> `MathF.Round(x, MidpointRounding.AwayFromZero)`.
- Structs with C++ default values (`HitboxDef`, `ProjectileDef`, `BeamDef`, `ProjShot`, `Platform`, `Color3`...)
  get `public static readonly T Default`; never `new T()`, `default` or `new T[n]` for them (C# 9 zeroes structs).
- Text: numbers parsed and printed with `CultureInfo.InvariantCulture`. Traces are compared as numbers, never as text.
- Trace line: `frame fighter state move moveFrame pos.x pos.y vel.x vel.y kb.x kb.y percent stocks`, ints as `%d`,
  floats `%.4f` (C#: `((double)f).ToString("F4", InvariantCulture)`). Tokens with a `.` compare within 0.01, the
  others exactly.

## Review Focus
1. **French locale:** reading or writing a number on yoyo's fr-FR PC gives the same result. Pinned: `ParityTests`
   run under fr-FR (Task 5).
2. **A C++ copy that C# shares:** `MoveDef m = c.moves[i]` or a by-value parameter edited in C# changes the static
   roster for the next match. Pinned: `Roster_UnchangedAfterMatch` (Task 5).
3. **A struct copy never written back** (`var p = plats[i]; p.x = ...`): a moving platform or projectile freezes.
   Pinned: the `moving_platform` scenario (Task 1 and 5).
4. **Static state between matches** (a cache, a counter, a shared `Rng`): a second match in the same process differs.
   Pinned: `Determinism_SameSeedSameHash` (Task 6).
5. **Mono float maths** (double intermediates): long fights drift. Pinned: `Float32_Probe` (Task 2) and the
   `cpu_vs_cpu_600` report (Task 6).

- Dumps: `sim_test trace stages` and `trace roster` (every sim field of every stage, character, move, weapon and
