## Notes
- A windowed player stalls after 3 frames while the screen is locked: vsync waits for the compositor, which shows
  nothing. The raylib game does the same. Run unattended checks with `-batchmode` (no window), or keep the screen
  unlocked. In batch mode frames run unpaced (thousands per second): before `--shot` or `--record` use it, step
  time 1/60 s per frame like the C++ (`Time.captureDeltaTime`).
- The Linux player reads a relative `-logFile` path from its own folder: pass an absolute path.
- `runInBackground` is on: the C++ loop never pauses, and Unity would freeze an unfocused window.
- Active Input Handling is set to the Input System in `ProjectSettings.asset` (no Unity API for it).
- The Unity project lives in `~/test-claude` itself. `.git/info/exclude` (local, not committed) holds the same
  ignore rules, so other branches of this clone don't show Unity's 3 GB of local files as untracked.
