# P0 · Unity project setup

Brief: `docs/unity/PORT_PLAN.md`, section "P0 · Project setup". Test first. Commands run from the repo root.
Unity binary: `$UNITY`, default `~/Unity/Hub/Editor/6000.6.9f1/Editor/Unity`.

### Task 1: Unity project, asset sync and the first test
Files: `unity/Packages/manifest.json`, `unity/ProjectSettings/` (written by Unity), `unity/.gitignore`,
`unity/Assets/Scripts/ClashHorizon.Game.asmdef` (covers `Game/` and `Gfx/`),
`unity/Assets/Scripts/Core/ClashHorizon.Core.asmdef` (no engine references),
`unity/Assets/Editor/ClashHorizon.Editor.asmdef`, `unity/Assets/Tests/EditMode/ClashHorizon.Tests.asmdef`,
`unity/Assets/Tests/EditMode/SetupTests.cs`, `scripts/unity_sync_assets.sh`, `scripts/unity_test.sh`.
- [ ] Manifest: URP 17.6.0, Input System 1.20.1, Test Framework 1.8.0, the audio module.
- [ ] Write `Setup_Works`: `Resources.Load<TextAsset>("Sprites/sheets").bytes` equals `assets/sprites/sheets.txt`.
- [ ] Run the EditMode tests before any sync (this first run also writes `ProjectSettings/`).
      Expected: `Setup_Works` fails with "Sprites/sheets missing".
- [ ] `unity_sync_assets.sh`: rsync `assets/sprites` to `Assets/Resources/Sprites`, `assets/audio` to
      `Assets/Resources/Audio`, `assets/fonts` to `Assets/Fonts`. Unity's `.meta` files are kept.
- [ ] `unity_test.sh`: sync, run the EditMode tests, print the counts, exit with Unity's code.
- [ ] Run `scripts/unity_test.sh`. Expected: 1 passed, exit 0; `git status` shows no synced file.
- [ ] Commit and push.

### Task 2: Boot scene, URP asset and builds
Files: `unity/Assets/Scripts/Game/GameMain.cs`, `unity/Assets/Editor/ProjectSetup.cs`, `unity/Assets/Editor/Build.cs`,
`scripts/unity_build.sh`; generated: `unity/Assets/Boot.unity`, `unity/Assets/Settings/`, `unity/ProjectSettings/`.
- [ ] `unity_build.sh linux|windows`: sync, run `Build.Linux` or `Build.Windows`, exit with Unity's code.
      Run it before `Build.cs` exists. Expected: fails (no `Build` class).
- [ ] `ProjectSetup.Run()`: a URP asset and renderer as the pipeline, Linear colour space, Mono backend, a
      1280x720 resizable window titled "Clash Horizon" (like `app.cpp`), no splash; `Boot.unity` with a camera and
      `GameMain`. `Build.Linux()` and `Build.Windows()` build `Boot.unity` into `unity/Builds/<Target>/`, exit 1 on
      failure. `GameMain` is empty at first.
- [ ] Build Linux and run the player with `--quit-after 60`. Expected: still running after 30 s.
- [ ] `GameMain` handles `--quit-after FRAMES`: quit at the end of frame FRAMES, like `app.cpp`.
      Expected: the player exits 0 by itself; without the flag it is still running after 15 s.
- [ ] `scripts/unity_build.sh windows`. Expected: exit 0 and `ClashHorizon.exe` is a PE32+ file (not run here).
- [ ] Commit and push.

Run `ProjectSetup` again after changing it:
`$UNITY -batchmode -nographics -quit -projectPath unity -executeMethod ClashHorizon.Editor.ProjectSetup.Run`.
