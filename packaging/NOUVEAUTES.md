## Installer

- **Linux** : télécharger `SuperClashBros-linux-x64.tar.gz`, le décompresser, puis lancer `./super_clash` dans le
  dossier `SuperClashBros` (Ubuntu 24.04 ou plus récent).
- **Windows** : télécharger `SuperClashBros-windows-x64.zip`, le décompresser, puis double-cliquer sur
  `super_clash.exe` (si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »,
  puis « Exécuter quand même »).

## Nouveautés

Version 9.8 : **des personnages nets**. Les animations PixelLab s'affichent enfin comme elles ont été dessinées.

- Le jeu faisait repasser chaque personnage dans un filtre « pixel art » prévu pour les anciens personnages
  dessinés par le code : il le réduisait (environ 87 pixels de haut au lieu de 213), écrasait ses couleurs, lui
  rajoutait un contour noir, puis le ré-agrandissait. D'où des personnages flous et pixelisés. Les animations
  PixelLab sont maintenant dessinées directement, à leur pleine résolution, en match comme dans les menus.
- Leur filtrage est réglé pour rester net quand un personnage est affiché plus petit que son dessin.
