CLASH HORIZON - version Linux (64 bits)
======================================

POUR JOUER
----------
1. Décompressez l'archive (clic droit > « Extraire ici »).
2. Ouvrez un terminal dans le dossier ClashHorizon
   (clic droit dans le dossier > « Ouvrir dans un terminal »), puis tapez :

       ./clash_horizon

   Si le terminal répond « Permission non accordée », tapez d'abord :

       chmod +x clash_horizon

Aucune installation n'est nécessaire : tout (polices, sons, musique) est
dans le fichier clash_horizon. Testé sur Ubuntu 24.04.

COMMANDES PAR DÉFAUT (modifiables dans Paramètres > Commandes)
--------------------------------------------------------------
Joueur 1 (clavier) : W A S D pour se déplacer (Z Q S D sur un clavier AZERTY)
                     Espace = saut, J = attaque, K = spéciale, L = bouclier,
                     I = saisie, O = attaque smash, U = ultime
Joueur 2 (clavier) : flèches pour se déplacer
                     clavier AZERTY : ; = saut, : = attaque, ! = spéciale,
                                      M = smash, ù = ultime
                     clavier QWERTY : , = saut, . = attaque, / = spéciale,
                                      ; = smash, ' = ultime
                     Maj droite = bouclier, Ctrl droit = saisie
                     (ou le pavé numérique : 0 saut, 1 attaque, 2 spéciale,
                     3 bouclier, 4 smash, 5 saisie, 6 ultime)
Échap ou P         : pause            F11 : plein écran

MANETTES (Xbox, PlayStation, Switch Pro, 8BitDo... reconnues automatiquement,
boutons modifiables dans Paramètres > Commandes avec la manette en main)
--------
Stick gauche ou croix = se déplacer   A = attaque       B = spéciale
X ou Y = saut                         LB = saisie       RB = ULTIME
LT ou RT (gâchettes) = bouclier       stick droit = attaque smash
Start = pause
(PlayStation : croix = attaque, rond = spéciale, carré/triangle = saut,
 L1 = saisie, R1 = ultime, L2/R2 = bouclier. Switch : les boutons gardent
 leur place, B = attaque, A = spéciale, ZL/ZR = bouclier, R = ultime.
 Manette sans gâchettes, style Super Nintendo : R = bouclier, Select = ultime.)

- La manette qui ouvre « Combat » devient celle du joueur 1. Une autre
  manette rejoint la partie en appuyant sur A (ou Start) dans la sélection
  des combattants.
- Si une manette se débranche en plein combat, le jeu se met en pause :
  rebranchez-la, elle retrouve son joueur.
- Quand une manette est branchée, l'écran affiche ses boutons ; appuyez sur
  une touche du clavier pour revoir les touches du clavier.

ASTUCES
-------
- Direction + attaque en même temps = attaque smash (maintenez pour charger).
- Donnez et recevez des coups (ou brisez l'Orbe Clash qui flotte au-dessus
  de l'arène) : quand « ULTI PRÊTE ! » s'affiche sur votre carte, appuyez
  sur ULTIME pour déclencher l'ultime de votre combattant !
- Tout le monde commence à mains nues. Les deux armes de chaque combattant
  tombent sur l'arène, l'une après l'autre : tenez-vous sur la vôtre et
  maintenez la touche ARME (E au clavier, Y à la manette) 2 secondes pour
  la prendre. Avec les deux, la touche ARME passe de l'une à l'autre.
  Les armes sont perdues au K.O.
- 5 combattants originaux et 5 arènes, en pixel art.
- Ordinateurs du niveau 1 au niveau 10 (le niveau 10 frappe deux fois plus fort).
- Les combattants sont en pixel art (Paramètres > Affichage pour revenir au
  dessin lisse).
- Le mode Entraînement permet de s'exercer contre un mannequin.

Les réglages sont enregistrés dans clash_horizon.cfg, à côté du jeu.
Si le jeu est lent, choisissez Paramètres > Affichage > Qualité graphique :
Normale (le jeu le fait tout seul si l'ordinateur n'arrive pas à suivre).

Polices : Luckiest Guy (Apache 2.0) et Poppins (SIL OFL 1.1). Manettes :
base SDL_GameControllerDB (zlib). Voir le dossier « licences ».
