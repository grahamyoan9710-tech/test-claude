CLASH HORIZON - Linux (64 bits)
===============================

JOUER
-----
1. Décompressez l'archive (clic droit > « Extraire ici »).
2. Ouvrez un terminal dans le dossier ClashHorizon et tapez :
       ./clash_horizon
   (si le terminal répond « Permission non accordée », tapez d'abord
   chmod +x clash_horizon). Testé sur Ubuntu 24.04.

COMMANDES (modifiables dans Paramètres > Commandes)
---------------------------------------------------
Joueur 1 : Z Q S D se déplacer, Espace sauter, J attaque, K spéciale,
           L bouclier, I saisie, O smash, U ultime, E arme
Joueur 2 : flèches se déplacer, ; sauter, : attaque, ! spéciale,
           Maj droite bouclier, Ctrl droit saisie, M smash, ù ultime, , arme
(touches d'un clavier AZERTY : le jeu affiche les vraies touches du vôtre)
Manettes : reconnues toutes seules.
Échap ou Start : pause.  F11 : plein écran.

À SAVOIR
--------
- Brisez la Clash Orb pour obtenir votre ultime, puis appuyez sur Ultime.
- Vos deux armes tombent sur l'arène : restez sur la vôtre et maintenez
  Arme 1 seconde pour la prendre.
- Si le jeu rame : Paramètres > Affichage, Qualité graphique Moyenne et
  RTX Non.
- Les réglages sont enregistrés dans clash_horizon.cfg, à côté du jeu.

Polices Archivo, Inter et Exo 2 (SIL OFL 1.1), base de manettes
SDL_GameControllerDB (zlib) : voir le dossier « licences ».
